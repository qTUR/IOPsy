# IOPsy — اجتماعات ثلاثية الأبعاد بروح سعودية

منصة اجتماعات في المتصفح: مخيم صحراوي (بيت شعر، نار، نخيل، قرية نجدية)، شخصيات كرتونية قابلة للتخصيص، صوت وكاميرا ومشاركة شاشة، وعارض (PDF / فيديو / شاشة) داخل الخيمة. نُقلت فكرتها من مشروع Unity «SLMM» (دون المساس بالأصل).

## التشغيل السريع
```
npm install
npm run meeting     # أو انقر start-meeting.bat
```
ثم افتح `http://localhost:3002` ← تبويب «المدير». كلمة السر تُطبع في أول تشغيل (تغييرها: `npm run admin:setpass -- <كلمة>`).
للاستضافة للمشاركين من الإنترنت: **HOSTING.md** (وفحص الشبكة: `node scripts/network-check.mjs`).

## المزايا
- **دخول**: المشارك بالاسم + كود الجلسة فقط (بدون حسابات أو بيانات). كود جديد لكل جلسة ويبطل بانتهائها. حد 20 مشاركًا. قفل الغرفة، طرد، إعادة اتصال تلقائية.
- **أدوار**: مدير (Owner) / مشرف (Moderator) / مشارك، وكل الصلاحيات تُفرض في الخادم.
- **الوسائط (LiveKit SFU)**: ميكروفون، كاميرا، مشاركة شاشة (ممنوعة افتراضيًا على المشارك ويمنحها المدير)، مؤشر التحدّث، جودة تكيفية.
- **الإدارة**: كتم فرد/الجميع، إيقاف كاميرا أو مشاركة، تقييد الميكروفون/الكاميرا/الشاشة فرديًا أو للجميع. **لا أحد يستطيع تشغيل جهاز غيره عن بُعد.**
- **العارض**: رفع PDF أو رابط Google Drive، تقليب الصفحات متزامنًا، فيديو متزامن (play/pause/seek)، عرض شاشة مشارك، عرض كامل بنقرة. مصدر واحد في كل مرة.
- **الدردشة**: عامة + رسائل خاصة (لا يراها المدير) + فقاعات فوق الشخصيات + تحيات (1–5).
- **ألعاب سعودية قديمة تفاعلية** (زر 🎲): **السيجة** (لاعبان على لوحة مرسومة في الرمل، 12 حجرًا لكل واحد، الأكل بالقفز إجباري، والبقية يتفرجون ويشجعون) و**الغميضة** (باحث يعدّ 15 ثانية ثم يبحث، والمختبئون خلف النخيل والكثبان؛ مؤشر حار/بارد، اكتشاف بالاقتراب، 120 ثانية) و**سباق الهجن** (حتى 10 متسابقين، عدّ تنازلي 4 ثوانٍ، الضغط بالتناوب يمين/يسار (A/D أو الأسهم أو الأزرار على الجوال) يقدّم جملك نحو خط النهاية، والبقية يشجعون بكاميرا السباق). القواعد كلها تُتحقَّق في الخادم.
- **كل المنصات**: كمبيوتر (Windows/Mac/Linux) وجوال (iPhone/Android) وتابلت، عمودي وأفقي. على الجوال: عصا حركة، سحب للدوران، قرص بإصبعين للتقريب، أزرار ركض/جلوس/تحيّات، لوحات سفلية، ويمكن «إضافته للشاشة الرئيسية» كتطبيق (PWA). جودة الرسوميات تنخفض تلقائيًا إن كان الجهاز بطيئًا.
- **العربية والإنجليزية** (RTL/LTR) + إعدادات الأجهزة والجودة.

| الصلاحية | مدير | مشرف | مشارك |
|---|:-:|:-:|:-:|
| كتم / إيقاف كاميرا أو مشاركة | ✅ الكل | ✅ المشاركون فقط | — |
| تقييد الميكروفون/الكاميرا/الشاشة | ✅ | ✅ (لا يتجاوز قيود المدير) | — |
| قفل الغرفة، طرد، ترقية/إلغاء مشرف، إنهاء الجلسة | ✅ | — | — |
| التحكم بالعارض ورفع الملفات | ✅ | — | — |
| عرض شاشته على العارض | ✅ | ✅ | إن مُنح الصلاحية |

## بنية المشروع
```
server/   index.mjs (الغرف والصلاحيات) · livekit.mjs · files.mjs (رفع/Drive/Range) · test.mjs · loadtest.mjs
src/      net.ts · media.ts · projector.ts · i18n.ts · store.ts · ui/* (الواجهة) · scene/* (العالم والشخصيات)
tools/    e2e2.mjs (اختبار متصفحات) · convert.py (تحويل أصول Unity عبر Blender) · لقطات التحقق البصري
scripts/  meeting.mjs · network-check.mjs
bin/      livekit-server.exe و lk.exe (من إصدارات LiveKit الرسمية؛ لا تُرفع للمستودع)
```

## المنصات المدعومة
| المنصة | الحالة |
|---|---|
| Chrome / Edge / Firefox على الكمبيوتر | كامل (بما فيه مشاركة الشاشة) |
| Safari على Mac | يعمل؛ مشاركة الشاشة محدودة (بدون صوت النظام) |
| Android (Chrome) | يعمل: صوت، كاميرا، ألعاب، عارض. **مشاركة الشاشة غير متاحة في متصفحات الجوال** (قيد من المنصة) |
| iPhone / iPad (Safari) | يعمل بنفس القيود؛ الميكروفون يتوقف عند قفل الشاشة أو تبديل التطبيق (قيد iOS) |
- الميكروفون والكاميرا في الجوال يحتاجان **HTTPS** (النفق يوفّره).
- جرّبتُ الجوال بمحاكاة لمس حقيقية (iPhone وAndroid وiPad، عمودي وأفقي) داخل Chrome؛ **لم أجرّبه على أجهزة فعلية** ولا على Safari الحقيقي.

## ما لم يُنجَز / حدود معروفة
- الاختبار بـ 20 متصفحًا حقيقيًا بكاميرات حقيقية لم يُجرَ (حاكيته أدوات LiveKit للحمل).
- مشاركة الشاشة اختُبرت بالتقاط وهمي من Chrome؛ جرّبها فعليًا على Chrome/Edge (Safari أقل دعمًا للصوت المشارَك).
- الشخصيات والمخيم مبنيان بالكود (إجرائيًا)، وليسا نماذج Unity الأصلية؛ جودتهما جيدة لكنها ليست بمستوى الفيلم المرندر.
- لا حسابات دائمة ولا سجل اجتماعات (بالتصميم).
